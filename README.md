# P0-Mosqueira-Javiera

Proyecto 0 — Introducción al benchmarking y al trabajo con agentes de IA.
Ramo: Métodos Computacionales en Ingeniería en Obras Civiles.

## Descripción

Este proyecto prepara un ambiente de trabajo para el curso y presenta una forma
de desarrollo basada en agentes de IA. Incluye:

- un script que investiga las características del computador (`src/system_info.py`);
- una multiplicación de matrices implementada con ciclos de Python (`src/mimatmul.py`);
- pruebas automáticas (`tests/test_mimatmul.py`);
- un benchmark que compara `mimatmul` con la operación optimizada de NumPy (`src/benchmark.py`).
